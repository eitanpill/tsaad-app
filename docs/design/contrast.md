## Rules for code (stage 3+)

- White on `#BB6F51` only for text >=19px bold (3.81:1). Smaller text on terracotta: use a cream chip with `#8A4A33` text.
- Text on sage/olive: forest `#123021` or `#8A4A33`, never `#BB6F51`.
- Links: `#8A4A33`, underlined.
- Day state is never color-only: fill level of the cup, solid vs dashed outlines, the "היום" tag and the day numbers carry it; the path tile also has an aria-label with the count.
- Focus: 3px `#123021` outline, 2px offset, 2px cream inner gap (works on light and dark tiles).
